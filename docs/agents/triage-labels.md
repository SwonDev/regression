# Etiquetas de triaje

| Rol canónico | Etiqueta de GitHub | Significado |
|---|---|---|
| `needs-triage` | `needs-triage` | Requiere evaluación del mantenedor |
| `needs-info` | `needs-info` | Espera información adicional |
| `ready-for-agent` | `ready-for-agent` | Está especificado y puede ejecutarse sin supervisión |
| `ready-for-human` | `ready-for-human` | Requiere una acción humana |
| `wontfix` | `wontfix` | No se implementará |

Las skills deben usar la columna de GitHub y no crear sinónimos.
